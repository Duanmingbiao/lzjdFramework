# 最小邮件闭环 v0.2

本工程已清空重建。MQ源码由我们编写；识别方式、图色参数、任务执行步骤和特殊情况处理尽量依据专业版的具体函数证据，缺少证据的情况不宣称已复刻。本轮补充QQ授权处理与独立登录总超时。

运行脚本 → 检测/启动游戏 → 默认QQ登录 → 自动处理已识别的QQ授权登录/同意/确认 → 使用当前已选区服 → 连续两帧确认大厅 → 邮件检查/领取 → 返回大厅 → 提交记录 → 等待下一轮。

首版仅登记任务1和168。没有扩展171项任务，也没有引入每日一次、星期/时间窗口、切号、多区或跨日任务重置。邮件使用独立间隔，默认21600秒；时间戳由手机系统Time()取得，重开脚本会读取保存记录，未完成则从入口重新执行。

## 手机助手测试

同步目标仍是手机助手已有的“日常任务开发”，保留原脚本ID和.prop。关闭已打开的旧脚本编辑页，不保存旧内容；同步后重新打开该脚本，保存设置并打包。若需文件导入，请使用dist/手机助手3.8导入版/日常任务.mq及同名.uip（GBK）。维护源码位于app、common、flows、ui，使用UTF-8 BOM/CRLF。

1. 模拟器设置720×1280、320 DPI，游戏已安装，使用已登录QQ及当前区服。
2. 将“邮件检查间隔”改为60秒方便观察；需要忽略上次等待记录时勾选“本次启动立即检查”。
3. 设置“启动到进入主页超时”，默认600秒，可填30～3600秒。该时间覆盖启动、加载、QQ授权、确认及回到游戏；QQ前台或确认页不会触发即时失败。对未识别的页面持续等待并输出前台包名和已用时间，验证码或账号选择仍可人工处理。
4. 只有确认邮件无可领取奖励、返回大厅并复核成功后，才输出“闭环完成”。没有奖励也属于正常检查完成，不会伪称领取了附件。
5. 在同一轮看到“闭环完成”后，检查是否保持等待、到间隔后重新检查邮件。

使用助手自带悬浮控制停止/暂停。首版未增加暂停回调或冻结计时策略；暂停期间TickCount的具体行为仍待助手实测。不要把暂停后恢复的计时行为当作已验证功能。

## 状态与恢复

统一结果：1成功、0等待、-1失败、-2超时。状态0等待、1执行、2返回大厅、4等待间隔、6恢复。未接入的3当日完成和5指定时间不生成占位业务。

使用原生WriteConfig/ReadConfig保存“最小闭环.邮件.*”：编号、启用、日期、开始/完成时间、下次时间、当前阶段、失败次数、完成轮次和未完成标记。写入立即落盘，提交有效标记最后写入；中断提交不视为成功。运行日志由Log.Open记录到GetTempDir()/log（助手原生目录），TracePrint也可在助手查看。

登录只使用“登录超时秒数”这一个总期限，不受普通操作超时、邮件间隔或写死180秒限制。登录起点在本次重连首次建立，跨QQ/游戏/确认页不重置；确认大厅才成功，达到期限仍未确认大厅才返回超时。登录流程不调用受普通超时约束的公共返回函数。顶层对任务1再检查登录期限，未到期限禁止KillApp。

邮件和普通返回仍检查进度超时，并保留180秒总上限。超时/失败由顶层关闭游戏、保留未完成状态，下轮重新连接并从邮件入口执行，无递归恢复及失败次数放弃上限。邮件检查间隔仅决定任务到期时间，不触发登录重启。

## 图色和当前限制

27组多点图色来自专业版V5.510的静态证据，其中8组为本轮新增QQ授权候选，来源/行号/参数见reference/图色来源.json。没有导入原版完整脚本。大厅判断组合前台包名、底部多点特征的两种布局候选之一、返回箭头缺失、已知弹窗缺失及连续两张截图。原版两套布局不是两个必须同时存在的菜单。未知遮挡、改版图标和字体差异仍须实测；不能保证所有遮挡均可被旧模板排除。

邮件使用原版两套布局的整页可领取/无奖励模板和锚点相对坐标。入口(25,830)只在大厅已确认时点击。QQ协议坐标(45,1150)只在登录页成立且未识别已勾选时尝试一次，之后继续在登录总期限内识别和等待；不连续切换复选框。

QQ授权登录、确定和同意分支参考root.793 L3947～4105，匹配锚点后点击并等待1000ms；一键登录按原版相对位置先点(x-151,y+86)、等1000ms，再点(x+63,y)、等1000ms。授权点击仅用于游戏或QQ包名，普通游戏任务仍只允许游戏前台。原版一套同意模板的y2=3000在当前1280高屏幕裁剪为1279，原始参数另行保留。

用户反馈旧版会在授权阶段重启；本轮修改尚未经过手机助手3.8官方编译或APK实机验证。已运行7项实际MQ控制流的模拟回归（时间/前台/找色API替身），覆盖QQ切换、超过旧180秒、同意确认、登录期限不重置、提前恢复拒绝、超时后恢复和一键登录偏移；模拟不证明真实图色命中。运行：`python -X utf8 validation/test_login_control.py`。
